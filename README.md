# Invaincu Ltd · Company site

Built with [Nuxt 4](https://nuxt.com) and generated as a static site.

```bash
npm install
npm run dev        # http://localhost:3000
npm run generate   # static site in .output/public
```

All the page content is in `app/pages/index.vue`. Colours and fonts are in `app/assets/css/main.css`.
